Ce que vous gérez

Une console unique pour le quotidien Docker — sans disperser les outils.

  • Conteneurs & stacks Logs, console, métriques, MàJ image en un clic, Compose multi-nœud.
  • Images & CVE Pull Hub / registres, build Dockerfile, pastilles Trivy automatiques.
  • Volumes & réseaux Named + binds, explorateur de fichiers, schémas d’usage.
  • Équipes & ACL Droits par nœud, partages de ressources, SSO Active Directory.
  • Clés API Générées dans le profil — mêmes droits que l’utilisateur (JWT ou X-API-Key).
  • Agents multi-nœuds Enrôlement HTTPS, pack ZIP, proxy Docker distant sécurisé.
