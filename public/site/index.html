Ce que vous gérez

Une console unique pour le quotidien Docker — sans disperser les outils.

  • Conteneurs Création, logs, console, inspect — actions en un geste.
  • Images & build Pull Hub / local, Dockerfile intégré, tags et registres.
  • Stacks Compose Éditeur YAML, variables d’environnement, déploiement fiable.
  • Volumes & réseaux Montages à la création, explorateur de fichiers sur volume.
  • Multi-utilisateurs Chacun voit ses ressources ; l’admin garde la vue globale.
  • Maintenance Prune des orphelins, tableau de bord et alertes moteur.
